# Engineering Standards

- **Correctness > performance > readability > brevity.** Never sacrifice correctness.
- **Minimal changes.** Smallest correct fix. No unrequested refactoring, abstractions, or features.
- **No defensive noise.** No null checks where types guarantee non-null. No error handling for impossible states.
- **No comments by default.** Only add a comment when the WHY is non-obvious to a future reader.
- **Follow the codebase.** Read before writing. Match style, naming, utilities, and patterns exactly.
- **Security always.** No secrets exposed. No injection vulnerabilities. Flag issues you notice.
