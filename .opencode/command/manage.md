description: Open the Agent Beehive manager popup
---

The Agent Beehive manager is a TUI popup — open it with the command palette:

1. Press **ctrl+p** (or your palette keybind) to open the command palette
2. Type **beehive** and press Enter

You'll see an arrow-key-navigable list of three hive templates:
- **Claude Hive** — Queen: claude-opus-4-8, requires Anthropic API key
- **OpenAI Hive** — Queen: gpt-4o, requires OpenAI API key  
- **Local Hive** — Queen: DeepSeek R1 14B, fully offline, no API key needed

Select a template and press Enter — the popup will tell you which agent to activate.
