:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Reimagined ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-reimagined](https://github.com/awesome-reimagined/awesome-reimagined) และ [reimagined.cafe](https://reimagined.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
